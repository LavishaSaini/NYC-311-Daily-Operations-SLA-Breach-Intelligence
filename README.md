# NYC 311 Daily Operations & SLA Breach Intelligence

## Project Overview

An end-to-end Data Analyst project analyzing NYC 311 service requests to identify complaint volume, response-time patterns, SLA breaches, and operational hotspots.

## Tools & Technologies

- SQL
- Excel
- Power Query
- Power BI
- DAX

## Key Analysis

- Complaint volume by borough
- Agency-wise workload analysis
- Response-time analysis
- SLA breach identification
- Closure-rate analysis
- Daily operational trends
- High-risk workload identification

## Project Workflow

Raw Data → Data Cleaning → Data Quality Checks → SQL Analysis → Excel Analysis → Power BI Dashboard → Business Insights

## Dashboard

The Power BI dashboard focuses on:

- Executive KPIs
- Agency SLA comparison
- Borough-level analysis
- Complaint-type analysis
- SLA breach monitoring
- Operational risk analysis

## Dataset

This repository contains a 100-row sample extract of NYC 311 service-request data for demonstration and portfolio purposes.

The sample is not intended to represent the complete NYC 311 dataset.

## Skills Demonstrated

- Data Cleaning
- SQL
- Excel
- Power Query
- Power BI
- DAX
- KPI Development
- SLA Analysis
- Data Visualization
- Business Analysis

## Business Objective

The objective is to move beyond simple complaint counting and identify which areas, agencies, and complaint categories require operational attention.

## Limitations

The analysis uses a limited sample dataset. Results may differ when applied to the complete NYC 311 dataset.
